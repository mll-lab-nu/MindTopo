# Separation One Stroke

`separation_one_stroke` is a TopoBench interactive planning task in the `separation` category.

The model sees one current-state board image at each turn and must output the next move as JSON:

```json
{"answer":"U"}
```

The benchmark uses multi-turn chat format. The first user turn contains the task, rules, answer format, and current task. Later user turns contain only the updated current task. Each turn sends the current board image as a separate image input.

## Difficulty

`board_size` is the setup level. Each setup is generated by sampling a legal no-loop construction path, filling color blocks inside the construction path regions, then recomputing the shortest solution with BFS. Difficulty is filtered by board size, color count, and the BFS shortest solution length.

- easy: `board_size = 4` (`4x4` cell board), 3 colors, shortest solution at least 9 steps
- medium: `board_size = 5` (`5x5` cell board), 3-5 colors, shortest solution 11-18 steps
- hard: `board_size = 6` (`6x6` cell board), 5-7 colors, shortest solution 19-20 steps

For each generated row, seed increments by 1 starting from `--seed-start 1`. Rows are generated board-size by board-size. Inside one board size, each repeat consumes the next seed.

Example: `--board-sizes 4 --repeats 100` produces 100 easy rows using seeds `1-100`.

Example: `--board-sizes 4-6 --repeats 2` produces rows in this order:

- `4x4` seeds `1, 2`
- `5x5` seeds `3, 4`
- `6x6` seeds `5, 6`

Each generated setup is accepted only after BFS finds a valid shortest solution in the configured range. The stored `solution` is that shortest solution, not the construction path.
`max_actions_per_traj` is `ceil(construction_path_length * 1.2)`, where `construction_path_length` is the originally sampled legal path length before BFS replacement.

## Generate Questions

`generate_samples.py` writes an interactive `question.jsonl`. It does not run the model and does not produce rollout images.

Generate easy questions:

```bash
cd /Users/andrewliu/Desktop/manling/topobench/environments/separation_one_stroke
conda activate ptm
python backend/generate_samples.py \
  --difficulty easy \
  --repeats 100 \
  --output-json output/question.jsonl
```

Generate medium questions:

```bash
python backend/generate_samples.py \
  --difficulty medium \
  --repeats 100 \
  --output-json output/question.jsonl
```

Generate hard questions:

```bash
python backend/generate_samples.py \
  --difficulty hard \
  --repeats 100 \
  --output-json output/question.jsonl
```

Generate multiple difficulties in one JSONL:

```bash
python backend/generate_samples.py \
  --difficulty easy,medium,hard \
  --repeats 100 \
  --output-json output/question.jsonl
```

Current generate defaults:

- `--board-sizes 4-6`
- `--difficulty ""` (when set, overrides `--board-sizes`)
- `--repeats 1`
- `--seed-start 1`
- `--generation-max-attempts 1000`
- `--generation-solver-timeout 2.0`
- `--output-json output/question.jsonl`

## Benchmark

Run from a generated `question.jsonl`:

```bash
cd /Users/andrewliu/Desktop/manling/topobench/environments/separation_one_stroke
conda activate ptm
python backend/internvl3_benchmark.py \
  --config ../api.json \
  --question-jsonl output/question.jsonl
```

Run a direct benchmark without a pre-generated JSONL:

```bash
python backend/internvl3_benchmark.py \
  --config ../api.json \
  --difficulty easy,medium,hard \
  --repeats 1
```

Run a local oracle check without calling the API:

```bash
python backend/internvl3_benchmark.py \
  --oracle \
  --difficulty easy \
  --repeats 1
```

Current benchmark defaults:

- `--board-sizes 4-6`
- `--difficulty ""` (when set, overrides `--board-sizes`)
- `--repeats 1`
- `--seed-start 1`
- `--generation-max-attempts 1000`
- `--generation-solver-timeout 2.0`
- `--max-tokens 0`
- `--output-json output/internvl3_separation_one_stroke.json`
- `--output-csv output/internvl3_separation_one_stroke.csv`
- `--image-root output`
- `--headless` enabled by default

Benchmark outputs:

- `output/question.jsonl`
- `output/model_answer.jsonl`
- `output/internvl3_separation_one_stroke.json`
- `output/internvl3_separation_one_stroke.csv`
- `output/internvl3_separation_one_stroke_by_level.json`
- `output/internvl3_separation_one_stroke_by_level.csv`
- per-step images and prompts under `output/{id}/`

Each step directory contains `step_0000_current.png`, `step_0000_prompt_debug.txt`, and `step_0000_pure_prompt.txt`.
